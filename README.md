# 🐍 지렁이 게임 (Snake Game)

웹 브라우저에서 바로 즐길 수 있는 HTML5 Canvas 기반의 클래식 지렁이(스네이크) 게임입니다.

## 🎮 게임 방법
- [index.html](index.html) 파일을 크롬, 엣지 등 웹 브라우저로 열면 바로 실행됩니다.
- **방향 전환**: 키보드 방향키 (`↑`, `↓`, `←`, `→`) 또는 `W`, `A`, `S`, `D`
- **일시 정지 / 계속하기**: `스페이스바 (Space)`
- 사과(빨간 원)를 먹으면 길이가 늘어나고 10점씩 점수를 획득합니다.
- 벽이나 자신의 몸통에 부딪히면 게임이 종료됩니다.

## 🛠️ 기술 스택
- HTML5 Canvas
- Vanilla JavaScript
- CSS3
